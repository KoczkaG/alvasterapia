# Irányítószám-adatbázis forrása

A `zip-cities.json` fájl a **GeoNames** nyílt földrajzi adatbázis magyarországi
irányítószám-állományából (`HU.zip`) származik, irányítószám → településnév(ek)
kereszttáblává feldolgozva.

- **Projekt:** GeoNames
- **URL:** https://download.geonames.org/export/zip/
- **Licenc:** Creative Commons Attribution 4.0 (CC BY 4.0)

Az adatot a licenc feltételeinek megfelelően, forrásmegjelöléssel használjuk.
A tartalmat átalakítottuk (irányítószámonként aggregáltuk a településneveket),
a jelentése nem változott. Tartalmazza a budapesti kerületi irányítószámokat
(1011–1239) és az osztott (több településhez tartozó) irányítószámokat is.
